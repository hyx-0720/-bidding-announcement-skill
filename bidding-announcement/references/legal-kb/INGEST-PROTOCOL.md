# 法律条款知识库 — 导入与校核规范（INGEST-PROTOCOL）

> 本规范约束 `references/legal-kb/` 的一切内容。**核心红线：法条文本必须真实、完整、可溯源，绝不可由模型生成或臆测。**

## 1. 合法性说明
- 中国《著作权法》第五条：法律、法规、国家机关的决议/决定/命令和其他具有立法、行政、司法性质的文件，不受著作权保护。**逐字转录法条原文合法。**
- 商业法律数据库（北大法宝、威科先行等）的**注释、解读、汇编编排**受版权保护——本库**只收法条原文，不照搬其注释/编排**。

## 2. 允许的来源（按权威性排序）
1. **官方一手来源**（人工检索/下载，非自动化爬取）：全国人大"国家法律法规数据库"、中国政府网政策文件库、财政部/国家发改委官网、中国政府采购网。
2. **官方公报**：国务院公报、全国人大常委会公报（PDF）。
3. **授权商业法律数据库及其 API**：需具备合法授权，带版本与时效信息。
4. **正式出版法规汇编**：法律出版社/中国法制出版社等正式出版物。

**禁止来源**：模型记忆生成、未注明出处的网络转载、AI 改写版、无法核验的二手摘录。

## 3. 录入流程（每条目必走）
1. 从允许来源取得**官方原文**。
2. **逐条转录**（条/款/项），保持原文，不增删不改写。
3. 填写完整**元数据**（见 `_TEMPLATE.md`）。
4. **第二人校核**：逐字比对原文，确认无误。
5. 在 `index.md` 标记该条目「校核状态 = 校核通过」与「最近核验日期」。

## 4. 效力状态管理
- 元数据「效力状态」取值：现行有效 / 已修订 / 已废止。
- 法规被修订：保留旧版本（标注失效日期）或新建版本文件，`index.md` 指向现行有效版。
- 法规被废止：标注「已废止」，**禁止用于生成正式公告**。

## 5. 生成守则（接入技能，硬性）
- 公告生成时，法定条款**只能逐字引用本库中「校核通过」的条目**。
- 本库**缺少**所需条款，或条目未达「校核通过」：必须提示「缺权威来源，待人工补充」，**不得由模型补写法条**。
- 现有 `references/clauses/` 中的固定条款，迁移期内应逐条标注来源并纳入本校核流程。

## 6. 更新周期
- 建议每季度或遇重大修法时，由人工对照官方来源复核全部条目时效，更新「最近核验日期」与「效力状态」。
