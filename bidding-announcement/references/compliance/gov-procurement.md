# 合规审查规则 — 政府采购（regime: gov）

> 配套脚本：`scripts/check_compliance.py --regime gov`。本场景为**强合规**。

## 审查维度与责任划分

| 维度 | 检查内容 | 判定方 |
|------|----------|--------|
| 法规完整性 | 含《政府采购法》第二十二条、财库〔2016〕125号信用条款、拒绝参加条款 | 脚本（关键词存在性） |
| 逻辑一致性 | 获取文件截止 ≤ 投标截止；预算 ≥ 最高限价 | 脚本（日期/数值比较） |
| 公告期限 | 公开招标投标期 ≥ 20 日；招标文件获取期 ≥ 5 个工作日 | 脚本（工作日未计法定节假日，需人工核实） |
| 歧视性条款 | 指定品牌/厂商、地域限制、注册资本门槛、以荣誉作条件、限定进口等 | 脚本扫词（仅提示）+ LLM/人工语义判定 |
| 政策符合性 | 中小企业预留份额、本国产品标准 | 脚本提示 + 人工判定 |

## 严重级别

- **错误**：违反强制规定，发布前必须修正（脚本退出码 1）。
- **警告**：疑似问题或确定性不足，需人工确认。
- **提示**：建议性事项。
- **通过**：该确定性检查通过。

## 输入 JSON（`fields` 关键项）

```json
{
  "text": "<公告全文>",
  "fields": {
    "procurement_method": "公开招标",
    "category": "engineering|goods|service",
    "publish_date": "YYYY-MM-DD",
    "doc_get_start": "YYYY-MM-DD",
    "doc_get_deadline": "YYYY-MM-DD",
    "bid_deadline": "YYYY-MM-DDTHH:MM",
    "budget_wan": 0, "ceiling_wan": null,
    "for_sme_only": false, "imported_goods_allowed": null
  }
}
```

## 脚本之外（LLM 必做语义审查）

判断资格/技术要求是否以不合理条件限制或排斥潜在供应商；技术需求是否指向特定品牌而无"或同等"；是否捆绑无关资质；限额以上项目是否应预留中小企业份额、是否落实本国产品政策。

## 呈现

先列「错误」并给具体修改建议，再列警告/提示；说明最终合规责任由采购人/代理机构承担。
