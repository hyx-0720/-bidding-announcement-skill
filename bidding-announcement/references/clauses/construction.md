# 工程建设招标法定条款库（regime: construction）

> 适用《招标投标法》及其实施条例场景（依法必招的工程建设项目及与工程有关的货物、服务）。
> **注意：本场景不使用政府采购法第二十二条/财库125号表述**，改用以下招投标法体系条款。条款原文引用，按需替换占位。

---

## 条款 C1：招标依据与招标条件（用于「一、招标条件」章）

本招标项目 [项目名称] 已由 [项目审批/核准/备案机关] 以 [批文名称及文号] 批准建设，项目业主为 [项目业主]，建设资金来自 [资金来源]，招标人为 [招标人]。项目已具备招标条件，现对该项目进行公开招标。

## 条款 C2：投标人资格要求（用于「投标人资格要求」章，按标的勾选）

1. 投标人应具备 [资质类别及等级]（如：建筑工程施工总承包 [等级] 及以上）资质，并在人员、设备、资金等方面具有相应的施工能力；
2. 投标人须具备有效的营业执照、安全生产许可证（施工类）等法定证照；
3. 拟派项目负责人须具备 [注册建造师等级及专业] 注册证书及有效的安全生产考核合格证书（B 证），且未担任其他在施建设工程项目的项目负责人；
4. *业绩要求：[近 N 年承担过类似项目业绩，按需填写]；
5. 本项目 [接受/不接受] 联合体投标。[接受时补充联合体资质与协议要求]

## 条款 C3：资格审查方式（默认包含，二选一）

本项目采用 [资格预审 / 资格后审] 方式对投标人进行资格审查。
- 资格预审：潜在投标人须先提交资格预审申请文件，通过预审后方可获取招标文件并参加投标。
- 资格后审：在开标后由评标委员会按招标文件规定的标准和方法对投标人资格进行审查。

## 条款 C4：投标保证金（按需包含）

投标人应在投标截止时间前提交投标保证金人民币 [金额] 元（不超过招标项目估算价的 2%）。投标保证金的形式为 [银行转账/银行保函/电子保函等]。

## 条款 C5：信用与失信限制（默认包含）

投标人不得被"信用中国"（www.creditchina.gov.cn）列入失信被执行人、重大税收违法案件当事人名单；不得处于被责令停产停业、暂扣或吊销执照、暂扣或吊销资质证书、财产被接管或冻结、破产状态。招标人将在投标截止时间对投标人信用记录进行查询，对存在上述情形者拒绝其投标。

## 条款 C6：发布媒介（依法必招项目，用于「发布公告的媒介」章）

本次招标公告同时在 [中国招标投标公共服务平台 / 省级公共资源交易平台 / 指定媒介] 上发布。对于因其他网站转载并发布的非完整版或修改版公告而导致误报名或无效报名的情形，招标人不予承担责任。

## 嵌入规则

| 条款 | 嵌入位置 | 触发条件 |
|------|----------|----------|
| C1 招标依据 | 一、招标条件 | 默认 |
| C2 资格要求 | 投标人资格要求 | 默认（按标的勾选项） |
| C3 资格审查方式 | 投标人资格要求 | 默认（用户选预审/后审） |
| C4 投标保证金 | 招标文件的获取 或 投标文件的递交 | 用户填写保证金 |
| C5 信用限制 | 投标人资格要求 | 默认 |
| C6 发布媒介 | 发布公告的媒介 | 依法必招项目默认 |
