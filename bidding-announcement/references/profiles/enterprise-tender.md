# Profile：企业自主招标（regime id: `enterprise`）

## 元信息
- 适用法律：《民法典》合同编；国有企业可注明"参照《招标投标法》执行"或上级国资监管规定。**无强制法定条款**。
- 适用范围：非依法必招的企业/国企自主采购或招标
- 标的类型：货物 / 工程 / 服务 / 综合
- 采购方式：公开招标、邀请招标、竞争性谈判、询比价、竞价（自由选择）
- 术语：招标人、投标人、中标人
- 条款库：`../clauses/common.md`（按需：免责、保密、招标人保留权利、最终解释权、联合体）
- 合规：**弱**，`scripts/check_compliance.py --regime enterprise`（仅逻辑一致性 + 歧视性提示，不检查强制法定条款）

## 自由度说明
本场景格式较自由：章节可按需裁剪，条款可选可不选，术语与文风可调整。下方为推荐通用结构，用户可增删。

## 问卷（阶段一收集，精简）

> ▎分组即"分步引导模式"的各步骤；【必填】缺失会提醒补充，（选填）可留空。本场景格式自由，选填项较多。

```
请提供以下招标信息：

▎步骤1 基本信息
- 招标人名称【必填】
- 项目名称【必填】
- 采购方式【必填】（公开/邀请/谈判/询比价/竞价）

▎步骤2 招标内容与范围
- 招标内容/标的【必填】（货物/工程/服务及主要要求、数量）
- 预算或最高限价（选填）
- 合同履行期限/交付要求（选填）

▎步骤3 投标人资格要求（整步可跳过；填写时避免不合理限制）
- 资格条件（选填，资质、业绩、规模等按需）
- 是否接受联合体（选填）

▎步骤4 获取与递交
- 获取招标文件：时间/地点或平台/方式/文件费用（选填）
- 投标截止时间【必填】 / 递交（开标）地点【必填】

▎步骤5 评标·其他·联系方式
- 评标方法简述（选填，最低价/综合评分等）
- 招标人是否保留不选最低价/重新招标等权利（选填）
- 联系人【必填】 / 电话（选填）/ 邮箱（选填）
```

## 生成规则
- 留空字段/章节省略；发布日期取当天。
- 不强制嵌入任何法定条款；用户需要时从 `../clauses/common.md` 选入（如免责声明、保留权利）。
- 资格条件提示用户避免歧视性/排他性表述（生成后合规审查会扫描提示）。

## 模板（输出 Markdown，章节可裁剪）

```
# [招标人][项目名称] 招标公告

## 一、项目概况
招标人：[招标人]
项目名称：[名称]
采购方式：[方式]

## 二、招标内容与范围
[招标内容/标的、数量、主要要求]
*预算/最高限价：[金额]（如填写）
合同履行期限/交付要求：[期限]

## 三、投标人资格要求
[资格条件各项]
*本项目( [接受/不接受] )联合体投标。

## 四、获取招标文件
时间 / 地点或平台 / 方式 / 费用

## 五、投标文件的递交
投标截止时间：[时间]
递交（开标）地点：[地点]

## *六、评标方法（如填写）
[评标方法简述]

## 七、其他事宜
*按需嵌入 common 条款：招标人保留权利 / 最终解释权 / 保密 / 免责声明。

## 八、联系方式
联系人 / 电话 / 邮箱

发布日期：[YYYY]年[MM]月[DD]日
```
