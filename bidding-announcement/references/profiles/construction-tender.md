# Profile：工程建设招标（regime id: `construction`）

## 元信息
- 适用法律：《招标投标法》及其实施条例、《工程建设项目施工招标投标办法》等
- 适用范围：依法必招的工程建设项目，及与工程有关的货物、服务（勘察/设计/施工/监理/重要设备材料）
- 标的类型：工程 / 与工程有关的货物 / 与工程有关的服务
- 采购方式：公开招标（默认）、邀请招标
- 术语：招标人、投标人、中标人、招标代理机构、`[采购方式]公告`
- 条款库：`../clauses/construction.md`（强制）、`../clauses/common.md`（免责/保密，可选）
- 合规：**强**，`scripts/check_compliance.py --regime construction`，规则见 `../compliance/construction.md`

## 问卷（阶段一收集）

> ▎分组即"分步引导模式"的各步骤；【必填】缺失会提醒补充，（选填）可留空。

```
请提供以下工程建设招标项目信息：

▎步骤1 招标条件（用途：说明项目合法性与资金来源）
- 项目名称【必填】
- 项目审批/核准/备案机关及批文文号【必填】（依法必招项目须经批准）
- 项目业主 / 招标人【必填】
- 建设资金来源【必填】（如：财政资金、国有企业自有资金、银行贷款等）

▎步骤2 项目概况与招标范围（用途：建什么、在哪建、招哪部分）
- 建设地点【必填】
- 建设规模/主要内容【必填】（含主要工程量或技术参数）
- 招标范围【必填】（如：施工总承包；或分标段说明）
- 标段划分（选填，如分多个标段请列明）
- 计划工期 / 服务期限【必填】（日历天或起止日期）

▎步骤3 投标人资格要求（用途：投标人门槛；注意与工程规模匹配、避免不合理限制）
- 资质类别及等级要求【必填】（如"建筑工程施工总承包三级及以上"）
- 项目负责人要求【必填】（注册建造师等级/专业、安全生产考核合格证等）
- 业绩要求（选填）
- 资格审查方式【必填】：资格预审 / 资格后审
- 是否接受联合体投标（选填，默认不接受）

▎步骤4 投标保证金（整步可跳过）
- 投标保证金金额（元）/ 形式（银行转账/保函等）（选填）
- 招标项目估算价（万元，选填，用于校验保证金不超过 2% 上限）

▎步骤5 招标文件的获取
- 获取起止时间【必填】 / 获取地点或平台【必填】 / 获取方式【必填】 / 文件售价（选填）

▎步骤6 投标文件的递交
- 投标截止时间（即开标时间）【必填】 / 递交（开标）地点【必填】

▎步骤7 发布媒介与联系方式
- 公告发布媒介【必填】（如"中国招标投标公共服务平台""xx省公共资源交易平台"）
- 招标人名称/地址/联系人/电话【必填】
- 招标代理机构名称/地址/联系人/电话（选填）
```

## 生成规则
- 发布日期取当天；留空字段/章节省略。
- 资格审查方式按用户选择（资格预审/资格后审）嵌入条款 C3。
- 投标保证金填写时嵌入条款 C4；未填写则省略。
- 法定条款按 `../clauses/construction.md` 嵌入规则原文嵌入；**不使用**政采第二十二条/财库125号。
