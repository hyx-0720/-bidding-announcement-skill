# Profile：政府采购（regime id: `gov`）

## 元信息
- 适用法律：《中华人民共和国政府采购法》及财政部相关法规
- 发布平台：中国政府采购网（www.ccgp.gov.cn）及省级分网
- 标的类型：货物 / 工程 / 服务（差异见 `../categories.md`）
- 采购方式：公开招标（默认）、邀请招标、竞争性谈判、竞争性磋商、询价、单一来源
- 术语：采购人、供应商、采购代理机构、`[采购方式]公告`
- 条款库：`../clauses/gov-procurement.md`（强制）、`../clauses/common.md`（免责，可选）
- 合规：**强**，`scripts/check_compliance.py --regime gov`，规则见 `../compliance/gov-procurement.md`

## 问卷（阶段一收集）

> ▎分组即"分步引导模式"的各步骤；【必填】缺失会提醒补充，（选填）可留空。按类别替换「合同履行期限」标签，仅货物类追加进口产品项。

```

▎步骤1 基本信息（用途：标明项目与采购人身份）
- 项目编号（选填，留空将标注[待补充]，如"ABC-2026-001"）

- 项目联系人【必填】 / 电话【必填】
- 采购代理机构名称、地址、联系人电话、邮箱（均选填）
```

## 生成规则
- 项目编号未提供则 `[待补充]`，绝不自动生成；发布日期取当天。
- 留空字段/章节省略，不留空行。
- 合同履行期限标签按类别替换（见 `../categories.md`）。
- 法定条款按 `../clauses/gov-procurement.md` 嵌入规则**原文嵌入**。
- 中小企业：用户选"专门面向中小企业"时嵌入条款 4。
