# 信息收集指引（模式选择 + 新手引导 + 分步协议）

> 阶段一选用。按用户对招标公告的熟悉程度提供两种收集模式，覆盖全部场景。

## 阶段一场：选择收集模式

信息收集前，先问：
> 在正式开始信息收集前，请选择您偏好的填写方式：
> **A. 一次性填写** — 将所有字段一次性列出，您可一次性填完或只填必填项（适合熟悉招标流程的用户，最快）。
> **B. 分步引导填写** — 按章节分组逐步引导，每步说明"这组字段是什么、哪些必填哪些不填、提供填写示例"（适合需要指引的新手用户）。

不继续直到用户选择。

## 一次性填写模式（模式 A）

直接显示所载入 profile 的完整问卷（含所有分组与选填标注），用户一次性提交全部信息。若用户提交的某个分组数据不全但必填项齐了，可生成（选填缺失自动省略）。

## 分步引导填写模式（模式 B）

### 新手开场（仅第一次使用本模式时说）

```
欢迎使用招标公告生成 Skill。接下来我将按章节分组，逐步引导您填写信息。
- 【必填】= 发布公告必须有的信息，缺了会提醒补充。
- （选填）= 可以留空，生成时自动省略。
- 任何一步都可以说"切换为一次性填写（模式 A）"转回全量问卷。
- 想问某字段什么意思？直接问（例："资质要求怎么填？"），我会解释并举例子。
```

### 分步协议（后续每步）

**每步格式：**

```
━━ 进度：[N]/[总数]

▎[分组名称]

本组用途：[一句话解释这组字段是公告的哪个部分、为什么需要填]。

① [字段名]【必填】— [一句话解释 + 填写示例]
② [字段名]（选填）— [解释 + 示例]
...

请填写上述信息（选填项可跳过；说"继续"使用默认值并进入下一步；说"全部默认"跳过所有后续步骤中的选填项；说"切换为一次性填写"转为模式 A）。
```

**收到用户回复后：**
- 若必填项不完整：提示具体缺了哪几项，重新显示缺失字段，等待补充。
- 若必填项齐了：确认"本组必填项已齐"，进入下一步。
- 用户说"继续"或"跳过"或"下一步"：所有选填留空，进入下一步。
- 用户说"修改 [字段名] 为 [值]"：更新对应字段并回显。

### 分组映射（由各 profile 的 ▎ 分组决定；括号内为步骤数）

| 场景 | 步骤分组 |
|------|----------|
| 政府采购（gov） | 6 步：基本信息 → 项目基本情况 → 资格要求 → 获取文件 → 投标/开标 → 联系方式（公告期限/补充事宜归入对应步骤） |
| 工程建设（construction） | 7 步：招标条件 → 项目概况与范围 → 投标人资格 → 投标保证金(可跳) → 获取文件 → 递交投标 → 联系方式 |
| 企业自主（enterprise） | 5 步：基本信息 → 内容与范围 → 资格要求 → 获取+递交 → 联系方式（评标/其他可跳） |
| 自定义（custom） | 走 profiles/custom.md 的组装子流程，本身就是分步引导 |

具体字段的【必填】/（选填）标注及示例在各 profile 文件的问卷中。

### 完成后
- 所有步骤完成后提示"全部必填项已收集完毕"，预览选填项缺失情况（列一个清单，不下 3 项），询问"补充选填项？直接生成？切换到某步骤修改？"。
- 选填缺失 > 3 项时列出缺失清单并问是否需要补充。
