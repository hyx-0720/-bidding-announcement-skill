# 章节积木库（sections library）

> 主要供 `custom` 场景组装使用，也是各 profile 章节的索引。每个章节含：用途、可用字段、适用场景。生成时留空字段省略。

| 章节 ID | 标题（可改） | 用途 | 主要字段 | 常见适用场景 |
|---------|--------------|------|----------|--------------|
| `overview` | 项目概况 | 一句话摘要：标的+获取方式+投标截止 | 项目名称、获取方式简述、投标截止时间 | gov / enterprise / custom |
| `tender_condition` | 招标条件 | 招标依据、资金来源、已具备招标条件 | 审批文号、资金来源、项目业主、招标人 | construction |
| `basic_info` | 项目基本情况 | 编号、名称、预算、需求、履行期限 | 项目编号、名称、预算、最高限价、采购需求、履行期限、联合体 | gov |
| `scope` | 项目概况与招标范围 | 建设地点、规模、招标范围、标段、工期 | 建设地点、建设规模、招标范围、标段划分、工期 | construction |
| `content_scope` | 招标内容与范围 | 标的内容、数量、预算、交付要求 | 招标内容、数量、预算/限价、履行期限 | enterprise / custom |
| `qualification` | 投标人/申请人资格要求 | 资格条件 | 资质、业绩、项目负责人、信用、联合体、资格审查方式 | 全部 |
| `get_doc` | 获取招标文件 | 时间、地点/平台、方式、售价 | 获取起止时间、地点/平台、方式、售价、（保证金） | 全部 |
| `submit_bid` | 投标文件的递交 | 投标截止、递交/开标地点 | 投标截止时间、递交（开标）地点、递交方式 | 全部 |
| `announce_period` | 公告期限 | 公告有效期 | 公告期限（默认 5 个工作日） | gov |
| `publish_media` | 发布公告的媒介 | 依法必招项目发布平台 | 发布媒介 | construction |
| `eval_method` | 评标方法 | 评标办法简述 | 最低价/综合评分等 | enterprise / custom |
| `others` | 其他补充事宜 | 政策、保留权利、免责等 | 发布媒介、政策清单、保留权利、保密、免责 | 全部 |
| `contact` | 联系方式 | 各方联系信息 | 招标人/采购人、代理机构、项目联系人 | 全部 |
| `custom_blank` | （用户自定标题） | 用户自定义章节 | 用户自填标题+正文 | custom |

## 字段→DOCX 映射提示
组装完成后，仍按 SKILL.md 导出阶段的 block 规则（title / section / subheading / body / body_indent）渲染；自定义样式经顶层 `settings` 传入 `render_docx.js`。
