# 招标公告生成 Skill — 使用说明（多场景）

## 功能概述

按用户**身份与类型**生成招标公告，覆盖五类场景，不同场景自动切换格式、术语、法定条款与合规强度。支持**中文 / English / 双语**三种语言，**一次性填写 / 分步引导**两种收集模式，一键导出 Word（.docx）与 PDF：

| 场景 | 适用法律/框架 | 法定条款 | 合规 |
|------|--------------|----------|------|
| 政府采购 | 政府采购法 | 强制（22条/125号/拒绝条款…） | 强 |
| 工程建设招标 | 招标投标法及实施条例 | 强制（资格审查/保证金/信用限制…） | 强 |
| 企业自主招标 | 民法典合同编（国企可参照招投标法） | 可选 | 弱 |
| 国际招标 | ICB/世行/亚行/FIDIC 等框架 | 标准条款 | 中 |
| 完全自定义 | 用户决定 | 自选/自填 | 关闭/提示 |

## 使用方式

对话中说"帮我生成一份招标公告"即可。AI 按顺序问你：

1. **身份/场景** — 五选一
2. **标的类型** — 货物 / 工程 / 服务（自定义在组装中决定）
3. **公告语言** — 中文 / English / 中英双语（国际招标默认 English）
4. **信息收集方式** — 一次性填写（熟手） / 分步引导（新手）

随后按该场景的问卷收集信息 → 生成 Markdown → 合规审查 → 导出 DOCX/PDF。

## 信息收集双模式

| 模式 | 适合 | 说明 |
|------|------|------|
| **A. 一次性填写** | 熟悉招标流程 | 全量字段一次列出，填毕即生成 |
| **B. 分步引导** | 新手 | 按章节分组逐步引导，每步说明用途、标注【必填】/（选填）并给示例 |

自定义场景另有两条路径：**A. 上传已有公告提取模板**（.docx/.md/.txt/.pdf）→ **B. 从空白自定**（术语→选章节→填字段→选条款→设样式→确认）。

## 法定条款的查找与引用

三级路径，绝不全文扫描 legal-kb（500KB）：

1. **clauses/*.md**（≤15KB，预提取高频条款，命中 90% 场景）
2. **CLAUSE-INDEX.md**（5KB，条号 → 文件路径快速映射）
3. **lookup_clause.py <文件> <条号>**（~50ms 精准提取；不定条号用 --search）

**守则**：条款只逐字引用已校核原文；缺失提示待补，绝不生成。

## 合规审查

生成后自动运行 `check_compliance.py --regime <场景>`：

| 场景 | 校验内容 | 级别 |
|------|----------|------|
| 政府采购 | 法定条款完整性+日期逻辑+20日+歧视性 | 强 |
| 工程建设招标 | 条款完整性+保证金≤2%+20日+歧视性 | 强 |
| 国际招标 | 英文条款完整性+30日ICB建议+英文歧视性 | 中 |
| 企业自主 | 仅逻辑一致性+歧视性提示 | 弱 |
| 自定义 | 默认关闭 | — |

报告分「错误 / 警告 / 提示 / 通过」；存在错误应先修正。

## 导出

- **DOCX**：`render_docx.js`（docx-js，Node），支持自定义字体/字号/主色/页边距。
- **PDF**：`render_pdf.py`（reportlab，内置 CID 中文字体 STSong-Light），与 DOCX 共用同一份 blocks JSON。

## 自定义自由度

术语切换、章节增删/排序、条款开关或自填、已有公告模板提取（.docx 可同步提取样式）、采购方式选择、字体/字号/主色/页边距/对齐、正式公文或简洁商务文风。

## 法律条款知识库

`references/legal-kb/` 含 12 部法规全文（500KB），覆盖政采/招投标/民法典体系。条款由人工从官方权威来源逐条转录，校核通过后方可用于生成。详见 `legal-kb/INGEST-PROTOCOL.md`。

## 环境前置

- Node.js + `npm install -g docx`（DOCX）
- Python 3 + `pip install reportlab pypdf`（PDF 读写）
- 可选：LibreOffice（旧版 .doc 转换）、pandoc（已有公告 .docx 内容提取）

## 目录结构

```
references/
├── regimes.md                  # 场景选择调度
├── intake-guide.md             # 双收集模式+新手引导协议
├── CLAUSE-INDEX.md             # 条款速查（条号→文件路径）
├── categories.md               # 工程/货物/服务差异
├── sections-library.md         # 章节积木库（自定义用）
├── profiles/                   # 五场景：问卷/模板/规则
├── clauses/                    # gov/construction/common/international 条款
├── compliance/                 # gov/construction/international 合规规则
└── legal-kb/                   # 12 部法规全文+导入校核协议+来源指南

scripts/
├── render_docx.js              # DOCX 渲染（docx-js，支持 settings）
├── render_pdf.py               # PDF 渲染（reportlab，CID 中文字体）
├── check_compliance.py         # 合规审查（--regime 分场景）
├── extract_style.py            # .docx 样式提取（字体/字号/页边距/标题色）
└── lookup_clause.py            # 条款精准提取（--index|<文件><条号>|--search）
```

## 常见问题

- **没有项目编号？** 留空，AI 标注 `[待补充]`。
- **想换其他采购方式？** 在选择或填写时说明，AI 自动调整。
- **生成后要改？** 直接告诉 AI 修改点。
- **某字段不会填？** 分步引导模式下直接问，AI 举例并解释。
- **法条会不会编造？** 不会。从 `legal-kb/` 或 `clauses/` 逐字引用，缺失提示待补。
